# Kiro journal

This file logs how Kiro features were used to build Phantom Inbox. Each line records the date, the Kiro feature and how it was used.

- 2026-11-07 | Specs | Wrote a requirements-first spec for the foundation step with EARS acceptance criteria, a design with ten correctness properties, and a task list. Each requirement was refined by a separate requirement-detailer agent before the design.
- 2026-11-07 | Steering | Added five always-included steering files for product, tech, structure, design system and security and privacy. They pin the token values, the Content-Security-Policy and the hook matchers that the code and tests copy.
- 2026-11-07 | Hooks | Added four hooks that run tests on save, write tests for new detection rules, check UI files for accessibility and contrast, and append a journal line after each task. Their regex matchers accept both slash styles and skip test files to avoid loops.
- 2026-11-07 | Agent | Built the scaffold, tests and hooks from the task list and gated the commit on typecheck, lint, 242 passing tests and a clean build. Fixed a TLS certificate error in npm by using the Windows certificate store.
- 2026-11-07 | Specs | Wrote the detection-engine spec and built a pure TypeScript engine with 17 rule files, 15 made-up sample messages and fast-check properties for score range, monotonicity, idempotent normalisation and empty input. All 383 tests pass, with every scam scoring 72 to 95 and every genuine message scoring 0.
- 2026-11-07 | Specs | Wrote the possession-check-ui spec and built the main screen with a message box, .eml file picker, sample menu, shape-coded verdict, numbered red flag cards and exact-word highlights. Component and axe tests caught a rule matching inside a URL, which was fixed in the engine with a regression test.
- 2026-11-08 | Specs | Wrote and built the haunted-view spec: a mansion backdrop, candle-lit cards, ghosts on the exact flagged words with True Name bubbles, countdowns and a burning score candle, all within reduced motion and AA contrast. A mobile performance script with a 4x slower CPU caught SVG repaints, and moving the flicker to overlay layers took scrolling from 31 to 52 fps.
- 2026-11-11 | Specs | Wrote and built the screenshot-and-exorcism spec: screenshots are read on the device with tesseract.js served from this site, and next steps follow the red flags found, with English and Hindi family warnings and a ghost-banishing ritual in Haunted view. A browser check of the production build read both test chats with no other origins, no storage and no CSP violations.
- 2026-11-11 | Agent | Audited every tracked file and the full git history for junk, secrets, personal data and unused code, and found no secrets. Replaced local project paths in the foundation spec and tests and extended the gitignore, keeping the whole .kiro folder tracked.
- 2026-11-11 | Specs | Wrote and built the seance spec: a 10-round real-or-scam game drawn from 29 made-up samples, with kind feedback from the real engine, keyboard play and a candle-lit table in Haunted view. Fast-check properties cover unique rounds, the 0 to 10 score, scam and genuine sample verdicts, and kind feedback wording.
- 2026-11-11 | Agent | Prepared the Vercel deploy with security headers from one vercel.json, a second policy for the OCR worker that a real browser proved necessary, a click-by-click README guide, a ghost favicon, page tags and a footer note, and set up the Playwright MCP server (this session had no MCP browser tools, so the journeys ran through a puppeteer script on Edge). The journeys found a page 49 to 61 px too wide on a 360 px phone and a 24 px checkbox, both fixed with regression tests, and lazy loading cut the first script from 326 kB to 309 kB.
- 2026-11-11 | Specs | Wrote the open-source-boosts spec and built a real domain parser (tldts and the Public Suffix List), a punycode decoder, Unicode confusables and a Majestic top-1000 list behind one lazy detection-data chunk of about 54 kB compressed. First-paint JavaScript and CSS grew by only 2.9 kB, and a documented pre-load mode keeps the checker working before the chunk arrives.
- 2026-11-11 | Property-based tests | Added fast-check properties for swapped look-alike letters, brand domains never flagged as their own lookalike, parsers that never throw, idempotent skeletons and a symmetric edit distance, each with 100 or more runs. A conformance test now fails if any property in the engine runs fewer than 100 times.
- 2026-11-11 | Behaviour changes | The foreign-script flag now fires only for mixed alphabets in one name or an xn-- name that cannot be decoded, so single-script names such as cafe with an accent are no longer flagged. Typosquat checks skip same-length swaps in short words, which stops ample.com and forges.com from being flagged at the cost of missing some real typos.
- 2026-11-11 | Evaluation | Added an eval script that runs the real engine over local .eml and mbox folders and prints precision, recall and false-positive rate. Only a smoke test on 6 made-up messages has run (4 of 4 phishing, 0 of 2 normal flagged), and the real Nazario and SpamAssassin numbers are pending the download.

It is kept in powers/phishing-forensics and could not be confirmed as installed or activated from this session, so it must be imported from the Powers panel.
